[0:00] Anthropic just shipped mods for Claude code. A few lines of TypeScript and Claude code shows how full your context is, stops the delete command before it runs, and replays every edit it just made. Hooks could not rewrite events, draw new UI, or replace built-in features. Mods can.

[0:19] Every time Claude code does something, it emits an event. Calling a tool, asking for permission, drawing part of the screen. A mod is one function hooked into that event, and it can run before it, after it, or instead of it. The hooks form a chain, like middleware.

[0:36] Yours runs, hands the event on, and at the bottom, Claude code does what it would have done anyway. Anthropic's first example is token weather, about 80 lines. A band above the prompt turns your context window into a forecast. One small file, clear at 18%. Four big files, showers at 67. One more, storm at 81%, a signal to wrap up the session.

[1:02] Blast radius goes further. Ask Claude to delete the build folder, and the mod holds the command. It lists the nine files it would remove, 1.1 megabytes, and waits. Press two, and Claude gets a refusal with the reason. Press one, and the command runs.

[1:18] Replay theater captures every edit in a turn. Claude renamed a function across three files in five edits. Press R, and a pane steps through each diff, one at a time.

[1:30] The bigger change is inside Claude code itself. Its own {slash} diff pane is now a mod, and so is the support for agents.md. The source sits in the public Claude code repo. Anthropic plans to move more built-in features to mods, so you can strip Claude code down to a small core, and add back only what you want.

[1:48] Describe the mod you want, and Claude writes it, installs it, and hot reloads it into your session. Mods are not sandboxed from your machine. They run with the same access as Claude code itself, and their publisher is not Anthropic. On team and enterprise plans and on managed machines, a built-in mod called sec default loads first and stops installed mods from overriding your permission deny rules. Anthropic also calls blast radius a safety net, not a permission system. A script that calls the delete command gets past it. Use mods for your own readouts and guards first. Those are worth it today. Skip the mods from strangers until you've checked their repo, and keep hard blocks in permission rules.
